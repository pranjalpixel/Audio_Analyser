# Audio_Analyser
A Python-based audio analysis tool that visualizes waveform, frequency spectrum, bass, mid, treble, and spectrogram data.

## Features

- Audio file selection using Tkinter
- Audio waveform visualization
- Frequency spectrum analysis
- Bass, Mid and Treble comparison
- Audio spectrogram
- Audio analysis report
- Dominant frequency range detection

## Technologies Used

- Python
- Librosa
- NumPy
- Matplotlib
- Tkinter

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run

python audio_analyser.py
